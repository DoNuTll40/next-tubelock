# คำถามที่พบบ่อย (FAQ)

> **ข้อควรรู้เรื่องพื้นที่จัดเก็บ:** TubeLock ใช้ OneDrive เป็นตัวกลางจัดเก็บเฉพาะชิ้นส่วนสำหรับเล่นสตรีมมิ่ง (`.m3u8`, `.ts`, `.m4s`) เท่านั้น ไฟล์ต้นฉบับที่อัปโหลดเข้ามาจะถูกลบอัตโนมัติหลังแปลงเสร็จ ไฟล์มาสเตอร์ดั้งเดิมยังคงอยู่กับเจ้าของผลงาน 100%

---

## 1. TubeLock คืออะไร และทำงานอย่างไร?

TubeLock คือแพลตฟอร์มสตรีมมิ่งวิดีโอส่วนตัวและชุมชนที่ใช้เทคโนโลยี **HLS Multi-bitrate (HTTP Live Streaming)** ผสานกับ Microsoft OneDrive เป็นคลังจัดเก็บชิ้นส่วนสตรีม, Neon PostgreSQL สำหรับข้อมูลและสิทธิ์เข้าถึง, และ GitHub Actions Workers สำหรับแปลงวิดีโอ 5 ช่องทางขนาน (5x Parallel Lanes) ทำให้เปิดดูได้เร็วตั้งแต่ `144p` ระหว่างรอความละเอียดสูงแปลงเสร็จ

## 2. ระดับการแสดงผล (`สาธารณะ` / `ไม่แสดงในรายการ` / `ส่วนตัว`) ต่างกันอย่างไร?

คุณสามารถตั้งค่าระดับการแสดงผลได้ทั้งตอนอัปโหลด (Step 4) และแก้ไขภายหลังในหน้า Studio:

| ระดับการแสดงผล | การค้นหาและหน้าแรก | ผู้ที่มีสิทธิ์รับชม |
| :--- | :--- | :--- |
| **สาธารณะ (Public)** | แสดงในหน้าแรก, ค้นหา, แฮชแท็ก และหน้าช่อง | ทุกคนสามารถค้นหาและรับชมได้ |
| **ไม่แสดงในรายการ (Unlisted)** | ไม่แสดงในหน้าแรกและผลการค้นหา | ทุกคนที่มีลิงก์วิดีโอสามารถเปิดดูได้ |
| **ส่วนตัว (Private)** | ซ่อนจากทุกหน้าสาธารณะ | เฉพาะเจ้าของวิดีโอและผู้ดูแลระบบเท่านั้น |

## 3. ระบบรองรับคุณภาพวิดีโอและเสียงระดับไหนบ้าง?

- **ความละเอียดสูงสุด 4K (2160p):** แปลงแบบ Adaptive Bitrate ครบตั้งแต่ `144p` → `360p` → `480p` → `720p` → `1080p` → `1440p (2K)` → `2160p (4K)`
- **รองรับ True HDR10 (AV1 10-bit):** สำหรับไฟล์ต้นฉบับ HDR ระบบจะคงค่าสีและเมตาดาต้า HDR10 แท้ในชั้น `1080p / 2K / 4K` และทำ Tone-mapping เป็น SDR ในชั้น `144p–720p` เพื่อรองรับทุกหน้าจอ
- **เสียง Hi-Res Lossless & Surround:** รองรับเสียงหลายแชนเนลตั้งแต่ `Mono` → `Stereo` → `5.1` → `7.1 Surround` และหากต้นฉบับเป็นเสียง Lossless/Hi-Res ระบบจะสกัดแทร็ก **PCM WAV / Auto-FLAC** ให้เลือกสลับฟังได้ในเมนูตั้งค่าตัวเล่น
- **รองรับหลายเวอร์ชันในคลิปเดียว (Multi-Version):** สามารถเพิ่มหลายเวอร์ชัน (เช่น ปกติ / Uncut / 4K) ไว้ใต้หน้าวิดีโอเดียวกันได้

## 4. ระบบซับไตเติล AI ทำงานอย่างไร?

ตอนอัปโหลดหรือในหน้า Studio คุณสามารถระบุภาษาเสียงพูดหลักของวิดีโอเพื่อให้ AI ถอดเสียงและแปลเป็นภาษาไทยให้อัตโนมัติ (รองรับทั้งไทย, ญี่ปุ่น, อังกฤษ, จีน, เกาหลี และอีกหลายภาษา — หากไม่แน่ใจว่าเป็นจีนสำเนียงไหน เลือก `จีนกลาง` ได้เลยเพราะระบบรับรู้ทุกสำเนียงจีนรวมกัน) หรือจะเลือก **ไม่มีเสียงพูด** เพื่อข้ามการสร้างซับ และยังอัปโหลดไฟล์ `.SRT` / `.VTT` เองได้เสมอ

## 5. การป้องกันภาพปก 18+ ทำงานอย่างไร และเปิดแสดงอัตโนมัติได้ไหม?

เพื่อความปลอดภัยและสบายตาในที่สาธารณะ วิดีโอที่ติดเรต `18+` หรือ `Restricted` จะถูกบังด้วยหน้ากากจำกัดอายุโดยค่าเริ่มต้นในทุกหน้า (หน้าแรก, ค้นหา, เพลย์ลิสต์, ประวัติ และแถบเพลย์ลิสต์มือถือ)

- ผู้ใช้ที่เข้าสู่ระบบแล้วสามารถกด **"แสดงภาพปก"** เป็นรายคลิปได้ทันที
- หากต้องการเปิดแสดงภาพปก 18+ อัตโนมัติในทุกหน้า ให้ไปที่ **การตั้งค่า → ความเป็นส่วนตัวและความปลอดภัย** แล้วเปิดสวิตช์ **แสดงภาพปกเนื้อหา 18+** (ระบบบันทึกอัตโนมัติและซิงก์ตามบัญชีของคุณ)

## 6. มีฟีเจอร์ช่อง `/@handle`, เพลย์ลิสต์ และ Floating Miniplayer ไหม?

มีครบครับ:

- **ช่องของฉัน (`/@handle`):** ตั้งชื่อ `@handle`, คำอธิบายช่อง และแบนเนอร์ได้ใน **การตั้งค่า → ช่องของฉัน** พร้อมระบบติดตามช่องจริง
- **เพลย์ลิสต์:** สร้างเพลย์ลิสต์ส่วนตัว/สาธารณะ จัดลำดับคลิปได้ พร้อมเพลย์ลิสต์อัตโนมัติ **ดูภายหลัง** และ **วิดีโอที่ชอบ**
- **Floating Miniplayer:** ย่อวิดีโอลงมุมจอได้ทั้งบน Desktop (ลากสลับได้ 4 มุม) และ Mobile/PWA เพื่อเลื่อนดูคลิปอื่นต่อโดยไม่สะดุด
- **ประวัติการรับชมแยกตามวัน:** จดจำจุดที่ดูค้างไว้และแยกประวัติเป็นรายวัน สามารถลบเฉพาะรายการหรือล้างทั้งหมดได้

## 7. การตั้งค่าต่าง ๆ ถูกบันทึกไว้ที่ไหน ต้องกดปุ่มบันทึกไหม?

**ไม่ต้องกดปุ่มบันทึกครับ** — ตั้งแต่เวอร์ชันล่าสุด ทุกการตั้งค่า (ธีมมืด/สว่าง, ความเร็วเริ่มต้น, สัดส่วนภาพ, ระดับเสียง, Autoplay, Stats HUD และสิทธิ์แสดงภาพปก 18+) จะ **Auto-save ทันที** ลงในเครื่องและซิงก์ขึ้นฐานข้อมูล **Neon DB** ตามบัญชีผู้ใช้ของคุณโดยอัตโนมัติ ทำให้ย้ายเครื่องหรือเปลี่ยนเบราว์เซอร์แล้วค่าเดิมยังตามมาด้วย

## 8. ทำไมหน้าพื้นที่จัดเก็บ OneDrive เห็นแค่คลิปของตัวเอง?

เพื่อความเป็นส่วนตัวของผู้ใช้งานทุกคน หน้า **การตั้งค่า → พื้นที่จัดเก็บ OneDrive** จะแสดงยอดความจุรวมของคลาวด์ควบคู่กับยอดใช้งานเฉพาะของคุณ แต่รายการโฟลเดอร์ HLS ด้านล่างจะกรองฝั่งเซิร์ฟเวอร์ให้แสดง **เฉพาะวิดีโอที่เป็นของบัญชีคุณเท่านั้น**

## 9. วิดีโอโหลดช้า หรือมีอาการ Buffering บ่อย แก้ไขอย่างไร?

1. กดปุ่มเฟือง (ตั้งค่า) บนตัวเล่นแล้วปรับความละเอียดเป็น **อัตโนมัติ (Auto)** หรือลดระดับลงให้เหมาะกับความเร็วเน็ต
2. หากเปิดโหมดเสียง **Hi-Res Lossless (WAV/FLAC)** อยู่ ลองสลับกลับเป็น **มาตรฐาน (AAC)** เพื่อลดแบนด์วิดท์
3. หากเปิดใช้งาน VPN หรือ Proxy ให้ลองปิดแล้วรีเฟรชหน้าเว็บ (หากดูต่อเนื่องเกิน 30 นาที ระบบจะรีเฟรชโทเค็นสตรีมให้อัตโนมัติอยู่แล้ว)

## 10. ใช้งานบนสมาร์ทโฟน แท็บเล็ต หรือติดตั้งเป็นแอป (PWA) ได้ไหม?

รองรับเต็มรูปแบบครับ มีหน้าตาและตัวเล่นแบบ Mobile-First รองรับการแตะสองครั้งเพื่อกรอซ้าย/ขวา, ลากแถบกรอพร้อมภาพพรีวิวเต็มจอ, แผงเพลย์ลิสต์แบบเลื่อนขึ้นจากด้านล่าง (Bottom Sheet), Picture-in-Picture และสามารถเพิ่มลงหน้าจอโฮม (Add to Home Screen / PWA) ได้ทันที
