# คำถามที่พบบ่อย (FAQ)

> **ข้อควรรู้เรื่องพื้นที่จัดเก็บ:** TubeLock มี OneDrive ทำหน้าที่เป็นตัวกลางจัดเก็บเฉพาะชิ้นส่วนไฟล์สำหรับเล่นสตรีม (`.m3u8`, `.ts`) เท่านั้น และ**ไม่มีการเก็บไฟล์คลิปเต็มต้นฉบับ**ของผู้ใช้งาน ไฟล์มาสเตอร์ดั้งเดิมจะยังคงอยู่กับเจ้าของผลงาน 100%

---

## 1. TubeLock คืออะไร และทำงานอย่างไร?
TubeLock เป็นแพลตฟอร์มสตรีมมิ่งวิดีโอส่วนตัวที่ใช้เทคโนโลยี HLS (HTTP Live Streaming) โดยระบบของเรามี Microsoft OneDrive ทำหน้าที่เป็นตัวกลางจัดเก็บข้อมูลสำหรับการสตรีม แต่เราไม่มีนโยบายเก็บไฟล์คลิปเต็มต้นฉบับของผู้ใช้งาน ไฟล์ต้นฉบับจะยังคงอยู่กับเจ้าของผลงาน 100%

## 2. ทำไมระบบถึงไม่เก็บไฟล์คลิปเต็มต้นฉบับ (Original Master)?
เพื่อให้สิทธิ์ความเป็นเจ้าของและไฟล์ต้นฉบับที่มีความละเอียดสูงสุดอยู่กับตัวเจ้าของงานเองอย่างปลอดภัย ระบบ TubeLock จะจัดเก็บบน OneDrive ตัวกลางเฉพาะ "ไฟล์ที่ระบบจำเป็นต้องใช้งานจริง" เท่านั้น ได้แก่ ไฟล์ Segment ย่อย (`.m3u8`, `.ts`, `.m4s`) สำหรับเล่นสตรีมมิ่ง, ภาพพรีวิว Storyboard และ Thumbnail

## 3. วิดีโอที่สตรีมผ่านระบบปลอดภัยแค่ไหน มีคนอื่นเข้าถึงได้ไหม?
วิดีโอมีความปลอดภัยสูงมาก ชิ้นส่วนไฟล์สตรีมที่อยู่บน OneDrive ตัวกลางจะถูกเข้าถึงผ่าน Signed URL ชั่วคราวที่ผูกกับการตรวจสอบสิทธิ์ OAuth 2.0 (Google / LINE) และมี Session Token ควบคุม ทุกคำขอสตรีมต้องผ่านการอนุญาตก่อนเสมอ

## 4. วิดีโอโหลดช้า หรือมีอาการ Buffering บ่อย แก้ไขอย่างไร?
แนะนำให้ลองตรวจสอบ:
1. โทเค็นการเชื่อมต่อ OneDrive ในหน้าตั้งค่า
2. ปรับระดับความละเอียด (Quality) ให้เหมาะกับความเร็วเน็ต
3. หากเปิดใช้งาน VPN หรือ Proxy ให้ทดลองปิด แล้วรีเฟรชหน้าเว็บ

## 5. สตรีมมิ่งแบบ HLS แตกต่างจากการเล่นไฟล์ MP4 ปกติอย่างไร?
HLS จะแบ่งวิดีโอออกเป็นไฟล์ย่อยๆ ทำให้เริ่มเล่นได้ทันทีโดยไม่ต้องรอโหลดทั้งไฟล์ขนาดใหญ่ ประหยัดแบนด์วิดท์ และทำให้การเลื่อนข้ามเวลา (Seek) ลื่นไหลแม่นยำ ไม่ต้องดาวน์โหลดไฟล์เต็มมาไว้บนเครื่อง

## 6. สามารถใช้งาน TubeLock บนสมาร์ทโฟนหรือแท็บเล็ตได้ไหม?
ใช้งานได้สะดวกมากครับ TubeLock รองรับ Responsive Interface ทั้ง PC, แท็บเล็ต และสมาร์ทโฟน รองรับ Gesture แตะสองครั้งข้าม 10 วินาที และการปรับสัดส่วนหน้าจอเต็มรูปแบบ
