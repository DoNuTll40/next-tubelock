# นโยบายความเป็นส่วนตัว (Privacy Policy)

> **สาระสำคัญ:** TubeLock มีบทบาทเป็นแพลตฟอร์มตัวกลางสตรีมมิ่งผ่าน Microsoft OneDrive โดยจัดเก็บเฉพาะชิ้นส่วนการเล่นวิดีโอ (HLS Segments) เท่านั้น และ**ไม่มีการเก็บหรือครอบครองไฟล์คลิปเต็มต้นฉบับ**ของผู้ใช้งาน ไฟล์มาสเตอร์ดั้งเดิมจะยังคงอยู่กับเจ้าของผลงาน 100%

---

## 1. สถาปัตยกรรมตัวกลางในการจัดเก็บ (Storage Intermediary Architecture)

TubeLock ให้ความสำคัญสูงสุดกับความเป็นส่วนตัวและสิทธิ์ในทรัพย์สินทางปัญญาของผู้สร้างสรรค์ ระบบของเราใช้ Microsoft OneDrive เป็น **"ตัวกลางจัดเก็บข้อมูล (Storage Intermediary)"** เพื่ออำนวยความสะดวกในการสตรีมมิ่ง แต่เรา **"ไม่มีนโยบายจัดเก็บไฟล์วิดีโอคลิปเต็มต้นฉบับ (No Original Master Retention)"** ที่ผู้ใช้อัปโหลดเข้ามา ไฟล์ต้นฉบับจะยังคงอยู่กับเจ้าของผลงานเสมอ สิ่งที่ระบบจัดเก็บบน OneDrive ตัวกลางมีเพียงชิ้นส่วนสตรีมมิ่งย่อย (HLS Segments) ที่จำเป็นต่อการเล่นบนเว็บเท่านั้น

## 2. ตารางการจัดการและประเภทข้อมูลที่ระบบบันทึก

| หมวดหมู่ข้อมูล | รายละเอียดข้อมูล | การจัดเก็บในระบบ |
| :--- | :--- | :--- |
| **ไฟล์คลิปเต็มต้นฉบับ (Original Master)** | `.mp4`, `.mov` (Full Quality) | ไม่จัดเก็บ (อยู่กับผู้ใช้งาน 100%) |
| **ชิ้นส่วนสตรีมมิ่ง (HLS Stream Artifacts)** | `.m3u8`, `.ts`, `.m4s` | จัดเก็บบน OneDrive ชั่วคราว (ตัวกลางสตรีม) |
| **ภาพตัวอย่างและสตอรีบอร์ด** | `poster.jpg`, `storyboard.vtt` | จัดเก็บบน OneDrive ชั่วคราว (สำหรับ Player) |
| **บัญชีผู้ใช้งาน** | Email, Display Name | Neon Database (ยืนยันสิทธิ์เข้าชม) |

## 3. บัญชีผู้ใช้และความปลอดภัยของข้อมูล (Account & Security)

การเข้าถึงข้อมูลและฟังก์ชันภายในแพลตฟอร์มทำงานผ่านกลไกความปลอดภัยระดับสากล:

- **OAuth 2.0 / NextAuth:** การเข้าสู่ระบบผ่าน Google หรือ LINE ดำเนินการผ่านโปรโตคอลมาตรฐาน ปลอดภัย โดยระบบไม่จัดเก็บรหัสผ่าน (Passwords) ใดๆ ของผู้ใช้
- **Signed URLs จำกัดเวลา:** การดึงชิ้นส่วนวิดีโอ (`.ts`) จาก OneDrive ดำเนินการผ่าน URL ชั่วคราวที่สร้างแบบ Realtime และมีอายุจำกัด เพื่อป้องกันการนำลิงก์ไปแชร์ต่อโดยไม่ได้รับอนุญาต
- **Session Cookie ปลอดภัย:** มีการเข้ารหัสระดับเบราว์เซอร์ด้วยแฟล็ก `HttpOnly` และ `SameSite` เพื่อป้องกันการโจมตีแบบ XSS และ CSRF

## 4. การไม่ติดตามข้อมูลและโฆษณา (Zero Tracking & Ads)

TubeLock ไม่มีนโยบายหารายได้จากการขายข้อมูลผู้ใช้ หรือการยิงโฆษณา เราไม่มีการติดตั้ง Google Ads, Facebook Pixel หรือสคริปต์บุคคลที่สามใดๆ ที่ทำการเก็บรวบรวมพฤติกรรมการใช้งานเพื่อการโฆษณา

## 5. สิทธิ์ของผู้ใช้ในการจัดการข้อมูล (Your Data Rights)

คุณมีสิทธิ์ในการเข้าถึง แก้ไข หรือลบข้อมูลส่วนบุคคลของคุณได้ตลอดเวลาผ่านเมนู **"การตั้งค่า (Settings)"**:

- คุณสามารถแก้ไขข้อมูลโปรไฟล์ อีเมล Gravatar ได้ในหน้าบัญชีและโปรไฟล์
- คุณสามารถลบวิดีโอหรือล้างประวัติการรับชม และใช้คำสั่ง "รีเซ็ตข้อมูลทั้งหมด" ได้ทันทีจากส่วนข้อมูลและความเป็นส่วนตัว
