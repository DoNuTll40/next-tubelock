# นโยบายความเป็นส่วนตัว (Privacy Policy)

> **สาระสำคัญ:** TubeLock ทำหน้าที่เป็นแพลตฟอร์มตัวกลางสตรีมมิ่งผ่าน Microsoft OneDrive โดยจัดเก็บเฉพาะชิ้นส่วนสำหรับเล่นสตรีมมิ่ง (HLS Segments, ภาพปก, Storyboard และแทร็กเสียง) และ**ไม่มีนโยบายเก็บไฟล์คลิปเต็มต้นฉบับค้างไว้หลังประมวลผลเสร็จ** ไฟล์มาสเตอร์ดั้งเดิมจะยังคงอยู่กับเจ้าของผลงาน 100%

---

## 1. สถาปัตยกรรมตัวกลางในการจัดเก็บ (Storage Intermediary Architecture)

TubeLock ให้ความสำคัญสูงสุดกับความเป็นส่วนตัวและสิทธิ์ในทรัพย์สินทางปัญญาของผู้สร้างสรรค์ ระบบใช้ Microsoft OneDrive เป็น **"ตัวกลางจัดเก็บข้อมูล (Storage Intermediary)"** เพื่อการสตรีมมิ่งที่ลื่นไหล:

- **ลบไฟล์ดิบอัตโนมัติหลังแปลงเสร็จ (No Original Master Retention):** ไฟล์วิดีโอต้นฉบับที่อัปโหลดเข้าโฟลเดอร์ชั่วคราว `/raw` จะถูกใช้เพื่อแปลงเป็น HLS Multi-bitrate และประมวลผล AI เท่านั้น จากนั้นระบบจะลบทิ้งอัตโนมัติเมื่อกระบวนการเสร็จสมบูรณ์
- **จัดเก็บเฉพาะชิ้นส่วนสตรีมมิ่ง:** สิ่งที่เก็บบน OneDrive (`/streams`) มีเพียงไฟล์ย่อยสำหรับเล่นบนเว็บ (`.m3u8`, `.ts`, `.m4s`, ภาพปก, Storyboard และแทร็กเสียง Hi-Res หากต้นฉบับรองรับ)
- **แยกสิทธิ์การมองเห็นคลังพื้นที่จัดเก็บ:** ในหน้า **การตั้งค่า → พื้นที่จัดเก็บ OneDrive** ผู้ใช้แต่ละบัญชีจะเห็นเฉพาะรายการวิดีโอและขนาดพื้นที่ของตนเองเท่านั้น ไม่สามารถมองเห็นชื่อคลิปหรือภาพปกของผู้อื่นได้

## 2. ตารางการจัดการและประเภทข้อมูลที่ระบบบันทึก

| หมวดหมู่ข้อมูล | รายละเอียดข้อมูล | การจัดเก็บในระบบ |
| :--- | :--- | :--- |
| **ไฟล์คลิปเต็มต้นฉบับ (Original Master)** | `.mp4`, `.mov`, `.mkv` | ใช้ชั่วคราวใน `/raw` ระหว่างแปลงไฟล์ แล้วลบออกอัตโนมัติ |
| **ชิ้นส่วนสตรีมมิ่ง (HLS Artifacts)** | `.m3u8`, `.ts`, `.m4s`, แทร็กเสียง Hi-Res | จัดเก็บบน OneDrive (`/streams`) สำหรับเล่นสตรีมมิ่ง |
| **ภาพตัวอย่างและสตอรีบอร์ด** | `poster.jpg`, `storyboard.vtt`, ซับไตเติล `.vtt` | จัดเก็บบน OneDrive และ Neon Database |
| **บัญชีและข้อมูลช่อง (`/@handle`)** | ชื่อ, อีเมล, รูปโปรไฟล์, `@handle`, Bio, แบนเนอร์, การติดตาม | Neon Database (ยืนยันตัวตนและแสดงหน้าช่อง) |
| **เพลย์ลิสต์และประวัติการรับชม** | เพลย์ลิสต์, ดูภายหลัง, วิดีโอที่ชอบ, ประวัติแยกตามวัน (`watch_history_log`), จุดดูค้าง | Neon Database (ซิงก์ข้ามอุปกรณ์เฉพาะบัญชีของคุณ) |
| **การตั้งค่าส่วนตัว (User Settings)** | ธีม, ค่าตัวเล่นเริ่มต้น, สไตล์ซับไตเติล, สิทธิ์แสดงภาพปก 18+ | บันทึกอัตโนมัติทั้งในเบราว์เซอร์และ Neon Database (`user_settings`) |
| **เซสชันอุปกรณ์ที่เข้าสู่ระบบ** | ชนิดอุปกรณ์, เบราว์เซอร์, OS, IP และตำแหน่งโดยประมาณ (GeoIP) | Neon Database (`user_sessions`) สำหรับตรวจสอบและสั่งออกจากระบบระยะไกล |

## 3. ความปลอดภัยและการควบคุมสิทธิ์การเข้าถึง (Account & Access Security)

- **OAuth 2.0 (Google / LINE):** เข้าสู่ระบบผ่านผู้ให้บริการมาตรฐานสากล โดยระบบ **ไม่จัดเก็บรหัสผ่าน** ใด ๆ ของผู้ใช้งาน
- **Session Cookie ปลอดภัย:** คุกกี้เซสชันถูกป้องกันด้วยแฟล็ก `HttpOnly` และ `SameSite=Lax` (พร้อม `Secure` บน HTTPS) และคุณสามารถดูหรือยกเลิกเซสชันของอุปกรณ์อื่นได้ตลอดเวลา
- **บังคับสิทธิ์ระดับการแสดงผล (`public` / `unlisted` / `private`):** วิดีโอที่ตั้งค่าเป็น **ส่วนตัว (Private)** จะถูกจำกัดสิทธิ์ทั้งหน้า Watch, API ดึงแหล่งสตรีม, ตัวกลางไฟล์ `/streams/*`, ภาพปก และ OG Preview ให้เข้าถึงได้เฉพาะเจ้าของและผู้ดูแลระบบเท่านั้น
- **Signed URLs จำกัดเวลา:** การดึงชิ้นส่วนวิดีโอจาก OneDrive ใช้ลิงก์ชั่วคราวที่มีอายุจำกัดและรีเฟรชอัตโนมัติเบื้องหลัง
- **ระบบคุ้มครองเนื้อหาจำกัดอายุ 18+:** ภาพปกและพรีวิวของคลิป 18+ จะถูกบังด้วยหน้ากากจำกัดอายุโดยค่าเริ่มต้นในทุกหน้า ผู้ใช้ที่เข้าสู่ระบบแล้วเท่านั้นจึงจะสามารถเลือกเปิดดูเป็นรายคลิปหรือเปิดใช้งานอัตโนมัติในการตั้งค่าได้

## 4. การไม่ติดตามข้อมูลและโฆษณา (Zero Tracking & Ads)

TubeLock ไม่มีนโยบายขายข้อมูลผู้ใช้งาน หรือติดตั้งระบบโฆษณา/ตัวติดตามพฤติกรรมจากบุคคลที่สาม (ไม่มี Google Ads, Facebook Pixel หรือ Ad Trackers ใด ๆ) ข้อมูลประวัติการรับชมและการกด "ไม่สนใจ" ถูกใช้เพื่อปรับปรุงคำแนะนำวิดีโอภายในบัญชีของคุณเท่านั้น

## 5. สิทธิ์ของผู้ใช้ในการจัดการข้อมูล (Your Data Rights)

คุณสามารถตรวจสอบ แก้ไข หรือลบข้อมูลของคุณได้ตลอดเวลาผ่านเมนู **การตั้งค่า (Settings)** และ **สตูดิโอ**:

- **จัดการช่องและบัญชี:** เปลี่ยน `@handle`, คำอธิบายช่อง, แบนเนอร์ และตรวจสอบ/ยกเลิกอุปกรณ์ที่ล็อกอินค้างไว้ได้ในแท็บ **บัญชีและความปลอดภัย** และ **ช่องของฉัน**
- **จัดการความเป็นส่วนตัวและประวัติ:** ลบประวัติการรับชมเป็นรายรายการ/รายวัน ล้างประวัติทั้งหมด หรือหยุดการบันทึกประวัติชั่วคราวได้ทันที
- **ลบวิดีโออย่างสมบูรณ์:** เมื่อคุณลบวิดีโอ ระบบจะลบทั้งข้อมูลใน Neon Database และโฟลเดอร์ไฟล์ HLS / ไฟล์ดิบที่เกี่ยวข้องบน OneDrive
- **รีเซ็ตข้อมูลในเครื่อง:** สามารถล้างจุดดูค้างหรือรีเซ็ตแคชเบราว์เซอร์ได้ทันทีจากแท็บ **ความเป็นส่วนตัวและความปลอดภัย**
