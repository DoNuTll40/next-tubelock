# ข้อกำหนดการใช้งาน (Terms of Service)

> **สรุปสาระสำคัญ:** TubeLock มีบทบาทเป็นแพลตฟอร์มตัวกลางสตรีมมิ่งผ่าน Microsoft OneDrive โดยจัดเก็บเฉพาะชิ้นส่วนการเล่นวิดีโอ (HLS Segments) เท่านั้น และ**ไม่มีการเก็บหรือครอบครองไฟล์คลิปเต็มต้นฉบับ**ของผู้ใช้งาน ไฟล์มาสเตอร์ดั้งเดิมจะยังคงอยู่กับเจ้าของผลงาน 100%

---

## 1. การยอมรับเงื่อนไข

การเข้าถึงหรือใช้งาน TubeLock ถือว่าคุณได้อ่าน เข้าใจ และตกลงที่จะปฏิบัติตามข้อกำหนดและเงื่อนไขการใช้งานเหล่านี้ ตลอดจนนโยบายความเป็นส่วนตัว หากคุณไม่ยอมรับข้อกำหนดเหล่านี้ โปรดยุติการใช้งานแอปพลิเคชันโดยทันที

## 2. ลักษณะการให้บริการและบทบาทตัวกลาง (Intermediary Role)

TubeLock เป็นแพลตฟอร์มตัวกลางอำนวยความสะดวกในการสตรีมมิ่งวิดีโอส่วนตัว โดยใช้ Microsoft OneDrive ของระบบเป็นพื้นที่จัดเก็บเฉพาะชิ้นส่วนไฟล์สำหรับการเล่น (`.m3u8`, `.ts`, Segments และ Storyboard) เท่านั้น:

- **ไม่มีการเก็บไฟล์คลิปเต็มต้นฉบับ:** ระบบไม่มีนโยบายจัดเก็บ ครอบครอง หรือทำซ้ำไฟล์มาสเตอร์ตัวเต็ม (Original Master Video) เพื่อให้สิทธิ์การถือครองและไฟล์ต้นฉบับอยู่กับผู้สร้างสรรค์ผลงานโดยตรง
- **การสตรีมผ่านสิทธิ์ปลอดภัย:** การเข้าถึงชิ้นส่วนวิดีโอทำงานผ่าน Signed URLs ที่มีการตรวจสอบสิทธิ์และจำกัดเวลาการใช้งานอย่างรัดกุม

## 3. ตารางเปรียบเทียบการเก็บข้อมูล (Storage Model)

| ประเภทไฟล์ (Asset Type) | การจัดเก็บบน TubeLock | ผู้ถือครองต้นฉบับ |
| :--- | :--- | :--- |
| **ไฟล์คลิปเต็มต้นฉบับ (Original Master)** | ไม่จัดเก็บในระบบ (No Retention) | เจ้าของผลงาน 100% |
| **ชิ้นส่วนสตรีมมิ่ง (.m3u8, .ts HLS)** | จัดเก็บบน OneDrive ชั่วคราว (ใช้เล่นสตรีม) | OneDrive ของระบบ (ตัวกลาง) |
| **ภาพพรีวิว (Poster, Storyboard)** | จัดเก็บบน OneDrive ชั่วคราว (สำหรับ Player) | OneDrive ของระบบ (ตัวกลาง) |

## 4. สิทธิ์ในผลงานและความรับผิดชอบต่อเนื้อหา

ผู้ใช้งานเข้าใจและยอมรับเงื่อนไขในการจัดการเนื้อหาดังนี้:

- ผู้ใช้งานเป็นเจ้าของลิขสิทธิ์หรือมีสิทธิ์ตามกฎหมายในเนื้อหาวิดีโอทั้งหมดที่นำมาประมวลผลผ่านระบบ
- ผู้ใช้งานมีหน้าที่เก็บรักษาและสำรองไฟล์คลิปเต็มต้นฉบับของตนเอง เนื่องจาก TubeLock ทำหน้าที่เป็นตัวกลางจัดเก็บเฉพาะชิ้นส่วนสตรีมมิ่งเท่านั้น
- ห้ามใช้งาน TubeLock เพื่อสตรีมหรือเผยแพร่เนื้อหาที่ละเมิดลิขสิทธิ์ ผิดกฎหมาย หรือขัดต่อศีลธรรมอันดี
