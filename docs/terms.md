# ข้อกำหนดการใช้งาน (Terms of Service)

> **สรุปสาระสำคัญ:** TubeLock ทำหน้าที่เป็นแพลตฟอร์มตัวกลางสตรีมมิ่งผ่าน Microsoft OneDrive โดยจัดเก็บเฉพาะชิ้นส่วนสำหรับเล่นสตรีมมิ่ง (HLS Segments) เท่านั้น และ**ไม่มีนโยบายครอบครองหรือเก็บไฟล์คลิปเต็มต้นฉบับ**หลังประมวลผลเสร็จ ไฟล์มาสเตอร์ดั้งเดิมยังคงอยู่กับเจ้าของผลงาน 100%

## 1. การยอมรับเงื่อนไข

การเข้าถึงหรือใช้งาน TubeLock ถือว่าคุณได้อ่าน เข้าใจ และตกลงที่จะปฏิบัติตามข้อกำหนดและเงื่อนไขการใช้งานเหล่านี้ ตลอดจน [นโยบายความเป็นส่วนตัว](/tubelock/policy) หากคุณไม่ยอมรับข้อกำหนดเหล่านี้ โปรดยุติการใช้งานแพลตฟอร์มโดยทันที

## 2. บทบาทตัวกลางและสถาปัตยกรรมการจัดเก็บ (Intermediary Role)

TubeLock เป็นแพลตฟอร์มตัวกลางอำนวยความสะดวกในการสตรีมมิ่งวิดีโอส่วนตัวและชุมชน โดยใช้ Microsoft OneDrive เป็นพื้นที่จัดเก็บไฟล์สตรีมมิ่ง (`.m3u8`, `.ts`, `.m4s`, Storyboard, ภาพปก และแทร็กเสียง Hi-Res):

- **ไม่เก็บไฟล์คลิปเต็มต้นฉบับถาวร:** ไฟล์ที่อัปโหลดเข้าโฟลเดอร์ชั่วคราว `/raw` จะถูกใช้สำหรับการแปลง HLS Multi-bitrate (สูงสุด 4K HDR10) และการประมวลผล AI แล้วลบออกอัตโนมัติเมื่อเสร็จสิ้น
- **ควบคุมสิทธิ์ตามระดับการแสดงผล:** ผู้สร้างสามารถกำหนดสถานะวิดีโอเป็น **สาธารณะ (Public)**, **ไม่แสดงในรายการ (Unlisted)** หรือ **ส่วนตัว (Private)** รวมถึงตั้งค่าความเป็นส่วนตัวของเพลย์ลิสต์ได้ตามต้องการ

## 3. ตารางเปรียบเทียบการเก็บข้อมูล (Storage Model)

| ประเภทไฟล์ (Asset Type) | การจัดเก็บบน TubeLock | ผู้ถือครองต้นฉบับ |
| :--- | :--- | :--- |
| **ไฟล์คลิปเต็มต้นฉบับ (Original Master)** | พักชั่วคราวใน `/raw` ระหว่างแปลง แล้วลบอัตโนมัติ | เจ้าของผลงาน 100% |
| **ชิ้นส่วนสตรีมมิ่ง (HLS `.m3u8`, `.ts`, `.m4s`)** | จัดเก็บบน OneDrive (`/streams`) สำหรับสตรีมมิ่ง | OneDrive ของระบบ (ตัวกลาง) |
| **ภาพพรีวิวและซับไตเติล (Poster, Storyboard, `.vtt`)** | จัดเก็บบน OneDrive และ Neon Database | OneDrive / Neon DB (สำหรับ Player) |
| **ข้อมูลบัญชี เพลย์ลิสต์ และการตั้งค่า** | จัดเก็บใน Neon Database แบบซิงก์รายบัญชี | ผู้ใช้งานสามารถแก้ไขหรือลบได้เอง |

## 4. สิทธิ์ในผลงาน การจัดเรตเนื้อหา และความรับผิดชอบ

ผู้ใช้งานเข้าใจและยอมรับเงื่อนไขในการเผยแพร่และจัดการเนื้อหาดังนี้:

- **สิทธิ์ในเนื้อหา:** ผู้ใช้งานรับรองว่าตนเป็นเจ้าของลิขสิทธิ์หรือมีสิทธิ์ตามกฎหมายในการนำวิดีโอมาประมวลผลและสตรีมผ่านระบบ
- **การสำรองไฟล์ต้นฉบับ:** ผู้ใช้งานมีหน้าที่เก็บรักษาไฟล์ต้นฉบับของตนเอง เนื่องจากระบบลบไฟล์ดิบหลังแปลง HLS เสร็จ
- **การจัดเรตเนื้อหา (Content Rating):** ผู้ใช้งานต้องระบุเรตเนื้อหา (`ALL`, `13+`, `18+`, `Restricted`) ตามความเป็นจริง ระบบอาจใช้ AI ช่วยตรวจสอบและปรับเรตให้เหมาะสมเพื่อให้กลไกคุ้มครองหน้ากาก 18+ ทำงานได้อย่างถูกต้อง
- **เนื้อหาต้องห้าม:** ห้ามใช้งาน TubeLock เพื่อเผยแพร่เนื้อหาที่ผิดกฎหมาย ละเมิดลิขสิทธิ์ หรือเป็นอันตรายต่อผู้อื่น

## 5. ฟีเจอร์ AI และการประมวลผลอัตโนมัติ

TubeLock มีเครื่องมือช่วยเหลือด้วย AI ได้แก่ **การถอดเสียงและแปลซับไตเติลอัตโนมัติ** และ **การประเมินเรตเนื้อหา** ผลลัพธ์จาก AI อาจมีความคลาดเคลื่อนด้านภาษา บริบท หรือเวลาไทม์โค้ด ผู้สร้างสามารถแก้ไขหรือแนบไฟล์ซับไตเติล (`.SRT` / `.VTT`) เองได้ทุกเมื่อในหน้า Studio

เพื่อให้ระบบสตรีมมิ่งทำงานได้อย่างเสถียรสำหรับทุกคน:

- ระบบมีการจำกัดอัตราการเรียกใช้งาน API (Rate Limiting) และโควต้าขนาดไฟล์/พื้นที่อัปโหลดต่อบัญชี
- ห้ามใช้สคริปต์อัตโนมัติในการดูดข้อมูล ปั๊มยอดรับชม หรือสร้างภาระผิดปกติต่อเซิร์ฟเวอร์และ GitHub Actions Workers

TubeLock ให้บริการในลักษณะ **"ตามสภาพที่เป็นอยู่" (As-Is)** โดยไม่รับประกันว่าการสตรีมจะปราศจากการหยุดชะงัก หรือข้อผิดพลาดที่อาจเกิดจากเครือข่าย ข้อจำกัดโควต้าของ Microsoft Graph API, Neon Database หรือ GitHub Actions
